## 4. 뉴스 수집 방법

### 4-1. 이광재 국회의원 언론보도 (3건)
```
검색 키워드 조합 예시:
- "이광재 국회의원 하남 {YYYY}년 {M}월 최신 언론보도"
- "이광재 의원 {법안/정책 키워드} {YYYY}년 {M}월 기사"
- "이광재 의원 예산결산특별위원장 하남 교산 {YYYY}년"
```

**수집 기준:**
- 최신 발행일 기준 3건 선택
- 각 기사당 2~3줄 요약 + 언론사명 + 기사 원문 URL 필수 기재
- 기사 배지(badge): 날짜 | 키워드 형식

**8월 수집 결과 예시:**
| 날짜 | 제목 (축약) | 출처 |
|------|------------|------|
| 2026.08.05 | 예결위원장 "국가 자산 3,500조 총동원" | 머니투데이 |
| 2026.08.03 | 강릉시 공직자 특강 – 지방 소멸 해법 | 강원일보 |
| 2026.08.01 | 동서울 변전소 '3+1 협의체' 제안 | 경인일보 |
| 2026.07.27 | 광화문초대석 출연 – 국가 리모델링 | KBS |
| 2026.07.22 | 국유재산 활성화법 패키지 3건 발의 | 경기일보 |
| 2026.07.15 | 이현재 시장과 교산 정책간담회 | 문화일보 |

## 5. HTML 뉴스레터 구조 설계

### 5-1. 전체 페이지 구조

```
[상단 네비게이션 바]
  ◀️ 뒤로가기 | ▶️ 앞으로가기 | 🏠 홈 | 날짜 정보

[헤더 박스] - 그라디언트 배경 (#1a365d → #2b6cb0)
  🏙️ 하남·감일·위례 지역 현안 & 의정 동향 보고
  YYYY년 MM월 DD일(요일)

[목차 (TOC)]
  1. 이광재 의원 언론보도
  2. 하남지역 신문 주요 뉴스
  3. 공공기관 소식지
  4. 네이버 하남 관련 인기 뉴스 Top 5
  5. ALL IN 하남라이프
  6. 맘카페 HOT 이슈 TOP 3

[Section 1] 🗣️ 이광재 의원 언론보도
  - 기사 카드 × 3 (badge + 제목 + 요약 + 출처/링크)

[Section 2] 📰 하남지역 신문 주요 뉴스
  - 기사 카드 × 2 (badge + 제목 + 요약 + 출처/링크)

[Section 3] 🏛️ 공공기관 소식지
  - 기사 카드 × 2 (badge + 제목 + 요약 + 출처/링크)

[Section 4] 🔥 네이버 인기 뉴스 Top 5
  - 번호 리스트 × 5 (제목 + 2-3줄 요약 + 언론사/링크)

[Section 5] 🎭 ALL IN 하남라이프
  - 2열 그리드 이벤트 카드 × 4~6개

[Section 6] 🔥 맘카페 HOT 이슈 TOP 3
  - 기사 카드 × 3 (badge + 제목 + 요약(현황/핵심/반응))

[하단 네비게이션]
  ◀️ 뒤로가기 | ⬆️ 맨 위로

[푸터]
  발행일 / 면책 문구
```

| 하남지역 신문 | 📰 | `#276749 → #38a169` (초록) |

| 네이버 인기뉴스 | 🔥 | `#9c4221 → #dd6b20` (주황) |
| ALL IN 하남라이프 | 🎭 | `#234e52 → #319795` (청록) |
| 맘카페 핫이슈 | 🔥 | `#d53f8c → #ed64a6` (분홍) |
