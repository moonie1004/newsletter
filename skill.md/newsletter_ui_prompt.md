## 3. 디자이너 전달용 작업 사양서 (국문)

### 주요 사양 및 톤앤매너
* **컨셉:** 깔끔하고 신뢰감을 주는 모던 비즈니스 스타일 뉴스레터 레이아웃
* **메인 컬러 파렛트:** 
  * Primary Accent: 청록 민트 (`#5BBAB5`)
  * Dark Background/Header: 짙은 차콜 슬레이트 (`#38434B`)
  * Main Background: 퓨어 화이트 (`#FFFFFF`)
  * Body Text: 어두운 회색 (`#2C3135`)
* **레이아웃 구성:**
  1. **Header:** 좌측 상단 세로형 민트 배너, 우측 상단 메인 타이틀
  2. **Hero Section:** 반투명 차콜 오버레이 박스가 들어간 메인 오피스 이미지
  3. **Body:** 좌측 차콜 강조 박스 + 우측 3단 썸네일 기사 리스트
  4. **Footer:** 다이아몬드 불릿 포인트를 활용한 3컬럼 토픽 요약 정보 영역
